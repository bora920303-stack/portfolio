PROJECT 01BI · 확산·SQL · Power BI

반복 자료 요청을 Power BI 셀프 조회로 전환

문제

해결

지표 기준 정리 + Power BI 조회 화면

결과

현업 직접 조회, 분석 시간 확보

6개현업이 고르는 조회 필터
0건발송 대상 중복 · 누락
어떻게 진행했나

수행

  • 반복 요청 지표와 집계 기준 정리
  • SQL Server에 연결한 Power BI 조회 화면 구축
  • 브랜드·지역·매장별 필터와 사용 기준을 현업에 제공

이후

  • 반복 집계가 줄어 고객 분석, 업무 자동화, 시스템 개선 과제를 병행할 수 있는 기반 마련

  • 회원가입일이 아닌 실제 첫 구매월 기준으로 코호트 정의
  • 반복되는 CRM 타깃 추출을 재사용 가능한 SQL 로직으로 표준화
